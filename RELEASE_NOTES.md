# Release Notes — v1.1.0 (порівняно з v1.0.0)

## Added
- Додано спеціальний базовий тариф доставки `80.0` для міста `"Kyiv"`.
- Додано явний параметр ставки податку `tax_rate` (зі значенням за замовчуванням `0.20`) для функції розрахунку стандартного рахунку.
- Додано окремі спеціалізовані функції `process_standard_invoice()` та `process_tax_exempt_invoice()` замість єдиної універсальної функції.

## Changed
- Коефіцієнт вартості доставки за вагу збільшено з `12.0` до `15.0` за кілограм.
- Виконано рефакторинг архітектурної зв'язності модуля `billing.py`: здійснено перехід від Common, Stamp та Control Coupling до еталонного Data Coupling.

## Breaking Changes
- Змінено сигнатури функцій розрахунку (`calculate_delivery_cost` тепер приймає примітивні параметри `city` та `weight_kg` замість об'єкта `CustomerProfile`).
- Видалено глобальну змінну стану `GLOBAL_TAX_RATE`.
- Видалено функцію `process_invoice()` та керуючий прапорець `mode_flag`.
